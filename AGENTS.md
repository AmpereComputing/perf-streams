# Instructions for AI agents

## Building

Build with `make`

## Testing

Run tests with `make test`

## Linting

Linting can be checked with `make check` and automatically fixed with `make
lint`.

## Coding format

* Follow C++ formatting set in `.clang-format` (uses `clang-format`)
* Follow Python formatting set in `pyproject.toml` (uses `ruff format`)

## Labeling

Any code modifications made by AI agents should be labeled as such, ideally in
a git commit message *and* in the code. Labeling via git messages is
*absolutely* required.

For git messages, use the following commit template:

    <SUMMARY_OF_CHANGE>
    <DETAILS_OF_CHANGE>

    Assisted-by: <AGENT_NAME>:<MODEL_VERSION>

For source comments (code-only), if a file/class is added with AI, there should
be a comment indicating so, in the following format:

    Assisted and/or generated by <AGENT_NAME>:<MODEL_VERSION>

Comments can be grouped semantically by block/function/class/file, etc.
Per-line labeling is *not* required.
